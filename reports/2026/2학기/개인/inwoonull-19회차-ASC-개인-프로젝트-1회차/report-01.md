- **작성자:** 송인우 (team03_01)
- **활동 기간:** 2026. 10. 26. ~ 2026. 11. 01.

## 프로젝트 진행 현황

- **이번 회차 목표:** 피싱 URL 탐지 원리, 활용 가능한 공개 데이터셋, Chrome 확장 프로그램 구조에 대한 사전 자료조사 및 전체 개발 방향 설정
- **현재 진행률:** 10% 
- **주요 달성 사항:** 피싱 URL의 대표적인 특징 정리, 모델 학습에 사용할 공개 데이터셋 후보 선정, Chrome 확장 프로그램 기본 구조 파악

## 수행 내역

> 이번 회차에 직접 수행한 작업을 구체적으로 적어 주세요.
> 산출물 링크(GitHub 커밋, PR, 분석 자료, 데모 등)가 있다면 함께 적어 주세요.

- **수행 작업:**
1. **피싱 URL 특징 조사**
     - 주소 형태 기반 특징: URL 길이, 특수문자 개수, 서브도메인 깊이, HTTPS 사용 여부 등
     - 의심 패턴: 단축 URL 사용, 유명 브랜드명이 포함된 도메인(타이포스쿼팅, 예: `paypa1.com`), `login`·`verify`·`secure` 등 의심 키워드 포함 여부
     - 위 특징은 URL만으로 빠르게 추출 가능하다는 점에서 확장 프로그램에 적합하다고 판단
  2. **공개 데이터셋 조사**
     - PhishTank, OpenPhish: 실제 신고된 피싱 URL 목록
     - UCI PhiUSIIL Phishing URL Dataset, Kaggle 피싱 URL 데이터셋: 정상/피싱 라벨이 함께 있는 학습용 데이터
     - Tranco 등 상위 도메인 순위 목록: 정상 URL 데이터 확보 및 화이트리스트 용도로 검토
  3. **AI 모델 방향 검토**
     - 1차로 결과 해석이 쉬운 머신러닝 모델(Logistic Regression, Random Forest 등)비교 예정
     - Random Forest 계열은 특징 중요도를 뽑을 수 있어 "판단 근거"를 사용자에게 보여주기 유리함
     
  4. **Chrome 확장 프로그램 구조 조사**
     - `chrome.tabs` API로 현재 접속 URL을 가져와 분석하고, 팝업 및 아이콘 배지로 위험도를 표시하는 구조로 설계
- **산출물 링크:**
     - 2차때부터 깃허브 산출물 예정
- **검증/확인 내용:**
     - 후보 데이터셋의 구성(정상/피싱 비율, 제공 컬럼)을 직접 확인하여 학습에 사용 가능한지 검토
