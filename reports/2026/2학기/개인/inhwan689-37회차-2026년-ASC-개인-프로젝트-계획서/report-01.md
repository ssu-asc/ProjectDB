## 프로젝트 개요

> AI가 존재하지 않는 패키지 설치를 추천하면, 공격자가 그 이름을 먼저 등록해 악성코드를 퍼뜨릴 수 있다. 기존 연구는 영어 기준뿐이다. 한국어·한영 혼용·국내 스택 프롬프트로 이 위험을 처음 측정한다.

## 기대 효과

- 한국어 환경의 패키지 환각률 첫 측정치
- 선점 위험이 큰 미등록 패키지 목록과 방어 권고

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 선행연구(USENIX Security 2025): AI 추천 패키지의 19.7%가 존재하지 않고, 같은 가짜 이름이 반복해서 나온다.
- 기존 연구·도구는 전부 영어 기준이라 한국어 환경의 위험은 알려지지 않았다.
- 가짜 이름은 실제로 등록하지 않는다. 측정과 권고까지만 한다.

## 2. 프로젝트 세부내용

- 프롬프트 200개: 같은 태스크를 영어·한국어·한영 혼용으로 작성 + 국내 스택(네이버, 카카오, 공공데이터 등) 태스크
- 오픈 코드 모델 3개 × 200개 × 10회 = 응답 6,000개 수집
- 응답에서 패키지 이름 추출 → PyPI·npm에 실존하는지 자동 판정
- 언어별·모델별 환각률, 반복 등장률, 미등록 위험 패키지 Top 50 산출

## 3. 프로젝트 기대효과

- 영어 중심 연구에 한국어 측정치 추가
- 위험 패키지 이름을 미리 공개해 선제 감시 가능
- 개발자용 설치 명령 검증 체크리스트 제공

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 무료 Colab GPU 시간 제한 → 나눠 실행하고 Drive에 저장해 이어 붙임
- 패키지 이름 오추출 → 회귀 테스트와 표본 수작업 검수
- 7B급 오픈 모델만 사용 → 상용 모델로 일반화하지 않음을 명시

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- 환경: Google Colab(T4 GPU), Python, vLLM
- 지식: 공급망 공격, PyPI·npm 레지스트리 API, LLM 추론

## 6. 프로젝트 수행시 활용되는 장비 및 물품

## 개인 수행 계획

- **주요 수행 항목:** 10월 수집·판정 자동화 → 11월 분석 → 12월 리포트 → 1~2월 공개·발표 준비
- **예상 산출물:** 위험 지도 리포트, 방어 체크리스트, GitHub 공개 저장소
- **검증 방법:** 실제·가짜 패키지로 판정 정확도 테스트, 원논문 19.7%와 같은 방식으로 대조
