> 웹 서비스에서 발생할 수 있는 대표적인 보안 취약점을 학습하고, 이를 자동으로 탐지할 수 있는 간단한 웹 취약점 진단 도구를 개발하는 것을 목표로 한다. 

## 기대 효과

-웹 서비스의 기본적인 동작 구조와 HTTP 요청/응답 과정 이해

SQL Injection, XSS 등 대표적인 웹 취약점의 발생 원리 학습

직접 공격을 수행해 보며 웹 해킹의 기본적인 과정 이해

Python을 활용한 간단한 보안 자동화 프로그램 개발 경험

공격뿐만 아니라 취약점 탐지와 대응 방법까지 함께 학

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

-웹 보안을 공부하면서 SQL Injection, XSS 등의 취약점을 단순히 문제 풀이를 통해 경험하는 것에서 나아가, 취약점이 발생하는 원리와 이를 탐지하는 방법을 직접 구현하며 이해하는 것을 목적으로 한다.

## 2. 프로젝트 세부내용

-프로젝트는 크게 웹 보안 기초 학습 → 취약 환경 구축 및 공격 실습 → 자동 진단 기능 구현 → 결과 분석 및 개선의 과정으로 진행한다.

## 3. 프로젝트 기대효과

-웹 서비스가 사용자 요청을 처리하는 과정에 대한 이해

주요 웹 취약점의 공격 원리 및 발생 원인 이해

Python을 이용한 HTTP 통신 및 자동화 프로그램 개발 경

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

-웹 및 네트워크에 대한 기초 지식이 부족하여 초기 학습 시간이 필요할 수 있음

취약점마다 탐지 방식이 다르기 때문에 모든 취약점을 자동으로 판단하기 어려울 수 있음

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

-Python 기본 문법

HTML 및 웹 서비스에 대한 기초 지식

HTTP 요청/응답 구조에 대한 이해

SQL Injection, XSS 등 기본적인 웹 취약점에 대한 이해

Python requests 등 HTTP 통신 라이브러리 사용법

## 개인 수행 계획

- **주요 수행 항목:** 웹 보안 기초 학습, 테스트용 취약 웹 환경 구축, SQL Injection 및 XSS 공격 실습, Python 기반 취약점 자동 탐지 기능 구현, 탐지 결과 분석 및 프로그램 개선
- **예상 산출물:** 테스트용 취약 웹사이트, Python 기반 웹 취약점 자동 진단 프로그램
- **검증 방법:** 직접 구축한 테스트 웹사이트에 취약점을 구현하고 자동 진단 프로그램을 실행하여 해당 취약점을 정상적으로 탐지하는지 확인한다. 이후 취약점을 수정한 상태에서도 동일한 테스트를 진행하여 탐지 결과를 비교한다.
