# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 대학 웹 서비스는 다양한 이용자의 개인정보를 처리한다. 그러나 보안 문제가 발생하면 다수의 이용자의 민감한 정보까지 유출이 될 가능성이 높다. 2026년 8월 한 대학교에서 개인정보 약 18만 건이 유출된 사례를 참고하여 이러한 공격 가능하게 했던 취약점과 공격 경로에 관심을 갖게 되었다. 이에 프로젝트를 통해 대학 웹 서비스에서 개인정보 유출이 발생할 수 있는 원인을 이해하고 개선 방안을 제안하고자 한다.

## 2. 프로젝트 세부내용

- Python 기반의 소규모 모의 웹 서비스를 구축하고 학생 로그인, 정보 조회, 관리자 조회 등 기능을 구현한다. 이 환경에서 반복 로그인 시도와 비인가 정보 조회에 따른 개인정보 노출 가능성을 분석한다. 또한 비인가 접근 시도의 탐지 가능성을 살펴보고 방어 기법 적용 시 작동을 비교한다.

## 3. 프로젝트 기대효과

- 인증과 접근제어 취약점이 개인정보 유출의 원인이 되는 것을 이해하고 대학 웹 서비스의 개인정보 보호 위험요인을 파악한다. 또한 방어기법 적용 전후를 비교하여 효과적인 보안 개선 방안을 살펴본다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 내부적으로는 웹과 인증, 접근제어에 대한 경험 부족으로 초기 개발과 모의 실험 과정에서 어려움이 있을 수 있다. 외부적으로는 개발 환경으로 인해 구현 가능한 기능이나 실험 범위에 제한이 있을 수 있다.

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- 기본적으로 WSL 기반 리눅스 환경, python, 웹 프레임워크, SQLite 가상 환경을 구성한다.
python과 웹의 기본적인 개발 지식과 HTTP, 인증, 세션, DB, 접근 제어 등의 기초적인 사전지식이 필요하다

## 개인 수행 계획

- **주요 수행 항목: 대학 개인정보 유출 사례를 조사하고 모의 웹 서비스를 구축한다. 이후 반복 로그인과 비인가 정보 조회 실험을 수행하고 로그인 제한과 서버 측 접근제어를 적용하여 방어 전후 결과를 비교 분석한다.**
- **예상 산출물: 모의 웹 서비스, 가상 데이터, 방어 전후 비교표**
- **검증 방법: 가상 데이터를 사용하여 모의 환경에서 방어 전후 실험을 반복한다. 인증 성공 여부 정보 접근 가능 범위, 비인가 접근 탐지 여부를 비교한다.**
