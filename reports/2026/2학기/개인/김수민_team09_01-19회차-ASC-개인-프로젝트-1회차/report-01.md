# [제 1차 개인 프로젝트 진행 보고서] ASC 개인 프로젝트 1회차

- **작성자:** 김수민 (team09_01)
- **활동 기간:** 2026. 10. 26. ~ 2026. 11. 01.

## 프로젝트 진행 현황

- **이번 회차 목표:** 개발 환경 구축 및 프로젝트 기초 개념 학습
- **현재 진행률:** 10% (전체 일정 대비)
- **주요 달성 사항:** Python·Wireshark 환경 세팅, TCP 소켓 통신 및 패킷 캡처 기초 학습

## 수행 내역

- **수행 작업:**
  - Python 개발 환경 및 Wireshark 설치
  - TCP 소켓 통신 구조(서버/클라이언트) 개념 학습
  - Wireshark 기본 사용법(로컬 루프백 캡처, 필터) 익히기
  - 프로젝트 전체 구조 설계: 컨트롤러(클라이언트) ↔ 로봇(서버) 명령 통신 시뮬레이션 → 평문 스니핑 → AES 암호화 적용 후 비교
- **산출물 링크:** 다음 회차부터 GitHub 업로드 예정
- **검증/확인 내용:** 로컬 환경에서 Wireshark로 루프백 트래픽 캡처되는 것 확인

## 이슈 및 해결 방안

- **문제 상황:** 중간고사 기간과 겹쳐 작업 시간 확보가 어려웠음
- **해결 현황:** 1회차는 환경 구축과 기초 학습 위주로 범위를 줄였고, 시험 종료 후 구현 작업 본격 진행 예정

## 다음 회차 목표

- Python으로 컨트롤러↔로봇 TCP 통신 프로그램 구현 (이동/정지 등 간단한 명령 송수신)
- Wireshark로 평문 명령 패킷 캡처 및 내용 확인
- AES 암호화 개념 학습 (대칭키, 운용 모드 등)

## 참고 자료

- Python 공식 문서 – socket 모듈
- Wireshark 공식 사용자 가이드
