| **프로젝트 분야** | 게임 보안, 리버싱, 시스템 보안 |

## 프로젝트 개요

> 최근 오픈 소스 게임 엔진으로 급부상 중인 **고도 엔진(Godot Engine)**의 구조를 분석하여 런타임 변조, 메모리 변조, 스크립트(GDScript) 탈취 등의 보안 취약점을 점검한다. 이를 바탕으로 실시간 무결성 검증 및 메모리 보호 기능을 갖춘 **전용 안티치트 솔루션**을 프로토타이핑하는 것을 목표로 한다.

## 기대 효과

- 오픈 소스 엔진 특유의 보안 허점 파악을 통한 시스템 보안 역량 강화
- 상용 엔진(Unity, Unreal) 대비 부족한 고도 엔진의 보안 생태계 기여
- 실무 수준의 안티치트 로직 구현을 통한 방어 기술 습득

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- **오픈 소스 엔진 분석:** 고도 엔진의 소스 코드가 공개되어 있는 이점을 활용하여 엔진 내부의 렌더링, 물리, 스크립팅 엔진의 동작 원리를 심층 분석한다.
- **취약점 대응책 마련:** Godot 기반 게임들이 증가함에 따라 발생할 수 있는 클라이언트 변조 및 메모리 핵 공격에 대한 선제적인 방어 체계를 연구한다.
- **맞춤형 보안 도구 개발:** 범용 안티치트가 아닌, 엔진의 특성(GDScript 바이트코드 등)을 고려한 최적화된 보안 모듈을 직접 설계한다.

## 2. 프로젝트 세부내용

- **엔진 바이너리 리버싱 및 취약점 분석:** Godot의 `SceneTree` 및 노드 관리 구조에서의 메모리 적재 방식 분석, 취약점 분석 진행.
- **공격 시나리오 구현:** Cheat Engine 및 디버거를 이용한 변수 값 조작, GDScript 디컴파일링 실험.
- **보안 모듈 개발:**
    - 메모리 난독화 및 중요 변수 암호화 라이브러리 제작.
    - 엔진 API 후킹 감지 및 프로세스 무결성 체크 루틴 구현.
    - GDScript 소스 보호를 위한 사용자 정의 패키징(PCK) 암호화 알고리즘 적용.

## 3. 프로젝트 기대효과

- **기술적 측면:** 게임 엔진의 내부 구조와 OS 레벨의 프로세스 보안 메커니즘에 대한 이해도 증진.
- **학습적 측면:** C++, Python, GDScript 등 다국어 프로그래밍 능력과 리버싱 도구 활용 능력 배양.
- **실무적 측면:** 보안 사고 발생 전 대응 가능한 분석 보고서 산출 및 오픈소스 기여.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- **오픈 소스 업데이트 대응:** 엔진 버전 업데이트에 따른 내부 구조 변경 시 보안 패치 호환성 문제.
- **성능 저하(Overhead):** 추가한 안티치트 로직으로 인한 게임 프레임 드랍 등의 성능 저하 발생 가능성.
- **학습 시간 소요:** 엔진 소스 코드 규모가 방대하여 핵심 로직 분석에 많은 시간 소요 예상.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- **구성원 역량:** C++ 언어에 대한 숙련도, x64dbg/IDA 등 리버싱 툴 기초 지식, OS API 이해.
- **개발 환경:** Godot Engine Source, Visual Studio, Python 등.
- **인프라:** 버전 관리를 위한 GitHub 프라이빗 레포지토리 및 기술 공유용 노션.
