## 프로젝트 개요

> 2027학년도 1학기 ASC 신입 모집에 활용할 취약점 실습 서버를 제작한다. 지원자 수준에 맞는 웹 취약점 문제와 풀이를 구성하고, 기존 Recruiting 서버와의 차별화를 위해 Flag 획득 및 실습 서버 또는 DB의 관리자 권한을 얻는 공격 시나리오 구현을 검토한다. 문제 제작부터 실행·풀이 검증, 초기화 방법과 문서 작성까지 진행한다.
> 

## 기대 효과

- 다음 학기 신입 모집에 활용할 수 있는 서버와 문제 자료를 마련하여 운영진의 제작 부담을 줄인다.
- 팀원들이 취약점 구현과 공격 재현을 직접 수행하며 웹 보안과 서버 운영 역량을 기른다.

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- ASC 신입 모집에 사용할 취약점 실습 서버를 제작하고, 이후에도 활용할 수 있는 문제·풀이 자료를 남긴다.
- 웹 취약점의 원리와 공격 과정을 직접 구현하고 검증하여 보안에 대한 이해를 높인다.
- 팀 역량과 개발 기간에 맞는 범위를 정해 실제 실행 가능한 결과물을 완성한다.

## 2. 프로젝트 세부내용

- **기존 Recruiting 서버 분석:** 기존 26-2학기 Recruiting 서버의 코드와 실행 환경을 검토하여 서비스 구조, 구현된 취약점, 문제별 풀이 흐름과 난이도, 배포·초기화 방식을 분석한다. 분석 결과를 바탕으로 재사용 가능한 요소와 개선점을 정리하고, 신규 서버의 문제 구성과 운영 방식 설계에 반영한다.
- **문제 조사·설계:** 기존 서버 분석 결과와 드림핵 등의 문제를 참고해 지원자 수준에 맞는 취약점 유형, 난이도, 문제 구성을 정한다.
- **학습·공유 방식 검토:** 팀원 수준과 가용 시간에 맞춰 웹 취약점을 공부·실습하고, 모임에서 원리·실습 결과·프로젝트 적용 아이디어를 짧게 발표하는 방식을 검토한다.
- **취약 서버 제작:** 의도적인 취약점이 포함된 웹 서비스를 구현하고, 문제별 풀이와 실행 환경을 구성한다.
- **추가 시나리오 검토:** Flag 획득과 실습용 가상머신의 root 권한 또는 DB 관리자 권한 획득을 목표로 하는 공격 경로의 구현 가능성을 조사한다.
- **환경 구성·검증:** 실습 환경의 분리·배포·초기화 방식을 정하고, 정상 기능과 의도한 풀이가 재현되는지 확인한다.
- **결과물 정리:** 서버 코드, 문제·풀이 문서, 실행·초기화 안내를 작성한다.
- **진행 계획:** 10월 14일 팀 회의에서 문제 콘텐츠, 환경·인프라, 단기 웹 해킹 학습 계획의 조사 결과를 공유하고 우선 구현 범위와 역할 분담을 정한다. 이후 기존 서버 분석·학습 → 문제 및 서버 설계 → 서버 구현 → 풀이 및 초기화 검증 → 최종 문서화 순으로 진행한다.

## 3. 프로젝트 기대효과

- 완성한 서버와 문제를 27-1학기 Recruiting에 활용할 수 있다.
- 취약점의 원인부터 공격 재현까지 경험하며 팀원들의 웹 보안 분석·개발 능력을 높인다.
- 실행·초기화 방법과 풀이를 문서화하여 다음 모집에서도 문제를 재사용하거나 개선할 수 있도록 한다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 신입 지원자 수준에 맞는 난이도를 정하고, 의도하지 않은 풀이와 정답 노출을 점검해야 한다.
- 서버·DB 관리자 권한 획득 시나리오는 구현 난이도가 높을 수 있어 조사 결과에 따라 범위를 조정해야 한다.
- 참가자가 root 또는 DB 관리자 권한을 얻으면 데이터 삭제·설정 변경으로 다른 참가자의 풀이에 영향을 줄 수 있다. 참가자별 가상머신 등 격리 환경을 검토하고, 네트워크·데이터 분리와 자원 제한이 제대로 동작하는지 확인해야 한다.
- 실습 서버가 손상되거나 DB가 삭제된 경우 해당 참가자의 환경만 원래 상태로 복구할 수 있어야 한다. 복구용 원본은 실습 환경 밖에 보관하고, 환경별 재생성 방법을 마련해야 한다.
- 시험 기간의 개발 공백과 서버 자원·비용을 고려해 구현 범위를 제한해야 한다.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- **구성원:** 배준성, 정희재, 지민혁 3명. 문제 조사·구현·검증에 참여하며 세부 개발 역할은 추후 정한다.
- **필요 역량:** 웹 서비스 개발, 웹 취약점 분석, Linux·DB의 기본 동작과 권한 구조 이해.
- **개발환경:** 웹 서비스·DB 개발 도구, 요청 분석 도구, 실습 서버를 실행하고 초기화할 수 있는 환경. 구체적인 기술 스택과 배포 방식은 조사 후 결정한다.
- **완료 기준:** 설계한 문제와 풀이가 정상 동작하고, 서버 실행·초기화 방법 및 풀이 문서가 준비되어 있는지 확인.
