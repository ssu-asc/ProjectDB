## 프로젝트 개요

> LLM Agent를 구현하고, Agent 사용 과정에서 발생할 수 있는 Prompt Injection 공격을 탐지하고 차단하는 보안 프로그램을 개발한다.

## 기대 효과

---
LLM Agent와 Prompt Injection에 대한 이해를 높이고, 방어 시스템 구현을 통해 AI 보안 시스템 설계 역량을 기를 수 있다.
# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- LLM Agent를 구현하고 Prompt Injection 공격을 분석하는 과정을 통해 AI 보안에 대한 이해를 높인다.
- 공격 유형에 따라 Gateway를 단계적으로 발전시키고 성능을 비교하여 효과적인 AI 보안 시스템 설계 방법을 알아본다.

## 2. 프로젝트 세부내용

- Llama 기반 LLM Agent를 구현하고, Agent가 외부 정보나 도구를 활용하는 과정에서 발생할 수 있는 Prompt Injection 공격을 분석한다. 이후 악성 프롬프트를 탐지하고 위험한 동작을 차단할 수 있는 보안 프로그램을 직접 구현한다.
- 처음부터 완성된 Gateway를 만드는 것이 아니라 공격을 수행하면서 버전을 하나씩 발전시키는 방식으로 진행한다.

## 3. 프로젝트 기대효과

- LLM Agent와 Prompt Injection의 이해도를 높이고 AI 보안에 대한 경험을 쌓을 수 있다.
- Gateway를 단계적으로 개선하고 성능을 비교함으로써 방어 기법의 효과와 한계를 분석할 수 있다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- LLM Agent 구현 경험이 없는 팀원도 있어서 LLM Agent와 Gateway 구현 과정에서 개발에 어려움이 발생할 수 있다.
- Prompt Injection 공격 방식이 다양하여 모든 공격 유형을 완벽하게 탐지하고 방어하기 어려울 수 있다.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- Llama 모델을 실행할 수 있는 Python 기반 개발환경이 필요하다.
