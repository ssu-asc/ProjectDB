## 프로젝트 개요

> 외부 AI 모델 파일을 불러오는 과정에서 발생하는 공개 취약점을 분석하고, 프레임워크의 보호 기능과 보안 패치의 효과를 검증한다. Keras를 우선 대상으로 공개 취약점 2건을 선정하여 격리된 환경에서 재현하고, 모델 로딩 경로와 패치를 분석한다. 버전·보호 옵션·실행 권한에 따른 결과를 비교하여 한 학기 동안 재현 환경, 검증 스크립트, 분석 보고서, 실험 결과표와 시연 영상을 제작한다.

## 기대 효과

AI 모델을 활용하는 과정의 보안 위험을 이해하고, 공개 취약점의 재현부터 원인 분석과 패치 검증까지 수행하는 실무 역량을 기른다. 실험 절차와 결과를 문서화하여 후속 연구 및 동아리 교육에 활용할 수 있는 자료를 확보한다.

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 외부 모델을 활용할 때 모델 로딩 과정에서 의도하지 않은 코드가 실행될 수 있다. 2026년 IEEE Symposium on Security and Privacy의 관련 연구를 바탕으로, 모델 파일을 처리하는 로더와 역직렬화 과정의 보안 문제를 학습한다.
- 공개 취약점의 발생 원인과 실행 조건을 소스 코드 수준에서 설명하고, 보안 패치 및 보호 설정의 효과를 실험으로 확인한다. 재현 가능한 코드와 분석 자료를 완성하는 것을 한 학기 프로젝트의 핵심 목표로 한다.

## 2. 프로젝트 세부내용

- 학기 전반부에는 최신 논문, 연구진의 공개 실험 자료, 공식 보안 공지와 수정 이력을 조사하여 Keras의 모델 로딩 관련 공개 취약점 2건을 선정한다. 사례별 Python·프레임워크·의존성 버전을 고정하고 가상 머신 안에 실험용 컨테이너를 구성한다. 공개 재현 코드를 검토한 뒤 테스트용 표식 파일 생성 등 무해한 동작으로 코드 실행 여부를 확인하고 실행 명령, 모델 파일의 해시와 로그를 기록한다. 중반부에는 모델 파일 구조, 객체 복원 과정과 함수 호출 경로를 추적하여 발생 원인을 설명하고, 취약 버전과 수정 버전의 소스 코드를 비교하여 패치의 검사 및 차단 조건을 분석한다.
- 학기 후반부에는 동일한 테스트 모델을 대상으로 버전, `safe_mode` 설정, 프로세스 권한과 네트워크·파일 접근 제한 조건을 비교한다. 코드 실행 여부, 오류 원인과 정상 모델의 로딩 성공 여부를 기록하고, 로더의 취약 동작 차단과 격리 환경의 영향 범위 제한을 구분하여 평가한다. 실험 결과를 검증 스크립트, 조건별 결과표, 최종 보고서와 시연 영상으로 정리한다. 기본 목표를 완료한 경우 추가 사례 1건 또는 다른 모델 로더의 유사한 경로를 검토한다.

## 3. 프로젝트 기대효과

- **분석 역량 향상:** Python 역직렬화와 AI 모델 로더의 동작을 이해하고, 취약점의 실행 조건을 확인하는 능력과 소스 코드·패치 분석 능력을 기른다. 보호 기능의 효과를 정상 모델과 취약점 재현 모델 모두를 이용해 검증하는 방법을 익힌다.
- **구체적인 성과물 확보:** 공개 취약점 2건의 분석 보고서, 버전이 고정된 재현 환경과 검증 스크립트, 보호 조건별 결과표, 최종 보고서 및 시연 영상을 제작한다. 저장소의 실행 안내서에 따라 다른 팀원이 실험을 재현할 수 있도록 구성하고, 이를 동아리 세미나와 후속 프로젝트 자료로 활용한다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- **외부 요인:** 공개 재현 코드와 패키지 버전의 호환성 문제, 의존성 배포 중단, 보안 공지와 코드의 설명 차이로 재현이 어려울 수 있다. 초기 조사에서 실험 가능성을 확인하고 버전 및 커밋을 고정하며, 환경 오류를 취약점 차단으로 오인하지 않도록 로그와 정상 모델의 실행 결과를 함께 점검한다.
- **내부 요인:** 모델 로더의 복잡한 구조와 팀원의 배경지식 차이로 분석 일정이 지연될 수 있다. 필수 범위를 사례 2건으로 제한하고 공통 기초 학습과 주간 진행 점검을 수행한다. 실험은 개인 자료와 인증정보가 없는 격리 환경에서 진행하고, 외부 통신과 호스트 파일 접근을 제한한다.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- **프로젝트 구성원:** 서병수와 양진우를 중심으로 2명이 수행하며, Python 프로그래밍, Linux 명령어와 Git 사용 능력을 바탕으로 모델 저장·로딩 및 역직렬화 개념을 학습한다. 주 1회 진행 상황과 실험 결과를 공유하고, 재현 결과와 분석 내용을 상호 검토한다.
- **개발환경 및 운영:** 실습실 PC에 가상화 및 개발 도구 설치가 가능한 환경이 필요하다. Linux 가상 머신, Docker, Python과 사례별 프레임워크를 사용하고 Git 저장소로 코드와 문서를 관리한다. 대규모 모델 학습 대신 소형 테스트 모델을 사용하며, 실험별 설정·의존성·로그를 보관한다.
