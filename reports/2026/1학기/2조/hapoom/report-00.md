## 프로젝트 개요

> 다수의 사용자가 실제로 이용하는 웹 서비스 환경과 동일한 테스트용 서버를 구축한다.
웹 및 서버 전반에 존재하는 취약점을 분석하여 공격 시나리오를 설계하고, 정보보안 관련 체크리스트를 작성하여 실제 서비스를 운용하기 위한 가이드라인 제시한다.

## 기대 효과
단순 웹 취약점 뿐 아니라 웹, 서버, 인증, 인프라 전반적인 취약점 분석하여 실제 서비스가 어떻게 구현되었는지를 파악한다.

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 실제 운용중인 서비스를 분석하여 이론적인 부분에서 벗어나 어떤 분야나 취약점이 발견되는지를 눈으로 보고 이해할 수 있다.
- 웹 취약점 → 서버 침투 → 권한 상승 과정을 학습할 수 있다.

## 2. 프로젝트 세부내용

- 웹 취약점을 기반으로 서버 침투 이후 내부 시스템으로 확장되는 공격 흐름 분석
- 침투 성공 시 권한 수준 확인 및 권한 상승 가능성 분석
- 권한 상승 및 내부 자원 접근 과정 분석
- 내부 시스템 접근 및 피보팅 가능 여부 분석
- 취약점 분석 결과를 기반으로 보안 체크리스트 및 대응 방안 작성



## 3. 프로젝트 기대효과

- 웹 , 서버 보안 통합 이해
- 실제 공격 시나리오 설계 능력 향상
- 보안 직무 대비

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 웹 관련 지식 부족
- 환경 구축, 서버 접근에 대한 허가에 문제가 발생할 가능성이 있다. (컨펌은 받았지만 어느정도의 권한이 주어지는지는 차후 협상예정)

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- 허가된 웹 서비스 접근 권한 확보
- 네트워크 구조 이해 필요
- 웹 취약점 + 흐름 이해
- 서버 접근 (RCE, 파일 업로드)

## 6. 프로젝트 수행시 활용되는 장비 및 물품

| 장비명/물품명 | 세부사양 |
|:---:|------|
| **H/W** | 개인 PC (Windows / macOS), 가상머신 환경 |
| **S/W** | Docker, Python, MySQL/SQLite, php |
| **기타(도서 등)** | Burp Suite, Wireshark |
