## 프로젝트 개요

> 개인적으로 진행하는 취약점 연구와 기술 학습에서 이해한 내용, 직접 확인한 결과, 시행착오를 기술 블로그 글로 정리한다. 여러 작업에 흩어진 기록을 다시 참고할 수 있는 글로 만들고, 다른 사람에게도 근거와 한계가 분명하게 전달되도록 작성한다. 기존 원고와 블로그를 활용해 현재 진행 중인 활동과 병행한다.

## 기대 효과

- 조사한 내용을 자신의 말로 설명하면서 이해가 부족한 부분을 확인하고 보완한다.
- 연구 과정과 결과를 재사용할 수 있는 기록으로 남겨 다음 작업의 참고 자료로 활용한다.
- ASC 개인 프로젝트의 결과물과 보안 분야 포트폴리오에 포함할 공개 글을 축적한다.

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 취약점 연구와 기술 학습을 여러 작업과 병행하고 있어, 그 과정에서 얻은 지식과 시행착오가 개별 메모에 흩어지기 쉽다. 직접 확인한 사실을 하나의 글로 정리해 이해를 점검하고 이후 연구에도 활용하고자 한다.
- 기존에 작성한 기술 글과 초안을 바탕으로 글쓰기 활동을 지속하고, ASC 개인 프로젝트로 확인할 수 있는 결과물을 만든다.

## 2. 프로젝트 세부내용

- 기존 원고와 새로 진행하는 연구·학습 기록에서 공개할 수 있는 주제를 선정한다. 보안 개념을 이해한 과정, 실습 중 확인한 동작, 도구 사용 경험, 공개 가능한 연구 결과 등을 다룬다.
- 각 글에 주제와 배경, 사용한 환경, 직접 관찰한 결과, 해석의 근거와 확인하지 못한 부분을 정리한다. 필요한 경우 LLM에 질문해 개념을 이해하거나 문장을 검토하되, 기술적 사실은 원자료와 실제 결과를 대조한다.
- Markdown으로 초안을 작성하고 사실관계와 공개 범위를 검토한 뒤 기존 기술 블로그에 발행한다. 2026년 남은 기간에는 **새 글 2편 이상 발행**을 목표로 한다.

## 3. 프로젝트 기대효과

- 기술적 현상을 관찰하고 원인과 한계를 설명하는 능력을 높일 수 있다.
- 자신의 연구·학습 기록을 공개 가능한 글로 정리하여 후속 연구와 동아리 활동에서 활용할 수 있다.
- 실제 작성·검토·발행한 글을 통해 지속적인 보안 학습 과정을 보여줄 수 있다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 다른 연구·학업 일정과 병행하면 글을 작성하고 검토할 시간이 부족할 수 있다. 기존 기록에서 글감을 고르고, 한 편씩 작성과 검토를 마무리한다.
- 아직 공개되지 않은 취약점이나 비공개 연구 자료가 글에 포함될 수 있다. 공개 가능 여부를 확인하고, 필요한 내용은 공개 시점 이후에 다룬다.
- LLM의 설명이나 오래된 자료를 그대로 사용하면 사실 오류가 생길 수 있다. 공식 문서와 직접 확인한 결과를 기준으로 다시 검토한다.

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- Markdown 문서를 작성하고 보관할 수 있는 개인 PC와 기존 기술 블로그의 게시 환경이 필요하다.
- 글의 주제에 맞는 기본적인 보안·개발 지식, 실습 기록, 공식 문서 또는 공개 자료가 필요하다. 모르는 내용은 실제 작업 중 찾아보고 정리한다.
- 연구 결과의 확인 범위와 공개 가능 범위를 판단하고, 기술 설명에 사용한 근거를 기록해야 한다.

## 6. 프로젝트 수행시 활용되는 장비 및 물품

|:---:|------|
| **H/W** | 기존 보유 개인 PC 1대, 인터넷 연결 |
| **S/W** | Markdown 편집기, Git, 웹 브라우저, 기존 기술 블로그의 편집 환경, 학습 보조용 LLM |
| **기타(도서 등)** | 기존 연구 기록과 블로그 초안, 주제별 공식 문서 및 공개 참고 자료 |

## 개인 수행 계획

- **주요 수행 항목:** 공개 가능한 주제 선정 → 기존 기록·실습 결과 확인 → Markdown 원고 작성 → 사실관계·공개 범위 검토 → 블로그 발행 및 오류 수정
- **예상 산출물:** 새 기술 블로그 글 2편 이상, 각 글의 Markdown 원고와 참고 자료 기록
- **검증 방법:** 발행한 글의 주소와 본문을 확인하고, 기술적 주장에 근거가 있는지, 직접 확인한 내용과 추정이 구분되는지, 비공개 자료가 포함되지 않았는지 검토한다.
