## 수행 내역

- **수행 작업:**
  1. **크랙미 시리즈 설계** — 각 레벨이 "정적 분석 / 동적 분석 중 무엇을 어렵게 만드는가"를 난이도 설계 기준으로 정함 (제작 과정에서 조정될 수 있음)

     | 레벨 | 핵심 기법 | 리버서가 배우는 것 |
     |---|---|---|
     | Lv1 | 하드코딩된 키 + 문자열 비교(strcmp) | 문자열 찾기, 비교 함수 직전에서 값 확인 |
     | Lv2 | XOR 인코딩 + 연산 검증 | 역연산, 바이너리 패치(분기 우회) |
     | Lv3 | 다중 조건 수식 검증 | 조건을 수식으로 옮겨 Z3(SMT 솔버)로 풀기 |
     | Lv4 | Z3로 풀기 어려운 검증(비선형·상태 머신) + 컴파일 옵션(-O0/-O2, strip) 비교 | 최적화·심볼 제거가 분석 난이도에 주는 영향 |
     | Lv5 | 안티 디버깅(ptrace, 타이밍 검사) | 디버거 탐지 원리와 우회 |
     | Lv6 | 제어 흐름 난독화 또는 패킹(UPX 등) | 정적 분석이 막혔을 때 동적 분석 활용 |

     - 플랫폼 선정 이유: Dreamhack 리버싱 강의·GDB·Z3 실습이 리눅스 기준이고, gcc 옵션 실험이 쉬우며, 팀 프로젝트 서버(리눅스)에 배포하기 쉬움
  2. **학습 로드맵 작성** — 회차별 학습 → 제작 → 셀프 풀이(write-up) → 보고서 순서로 진행

     | 회차 (마감) | 학습 | 제작 |
     |---|---|---|
     | 1 (11/01) | RE Unit 4·5·7 | 설계안 |
     | 2 (11/15) | Unit 6 IDA, Unit 9 rev-basic, Ghidra 1~2 | Lv1 |
     | 3 (11/29) | Ghidra 3~4(패치) | Lv2 + 패치 우회 실험 |
     | 4 (12/27) | Unit 10 SMT/Z3, Ghidra 5 | Lv3 + Z3 풀이 스크립트 |
     | 5 (01/10) | 컴파일 옵션·strip 실험 | Lv4 |
     | 6 (01/24) | Anti-Reversing | Lv5 + 우회 write-up |
     | 7 (02/07) | 난독화·패킹 조사 | Lv6 |
     | 8 (02/21) | — | 팀원·지인 테스트, 피드백 반영, write-up 통합 |

  3. **기초 학습**
     - x86-64 어셈블리: 레지스터 체계, mov/lea, 산술·논리 연산, cmp/test와 조건 분기, 스택과 함수 호출(call/ret), System V 호출 규약, 시스템 콜, 리틀 엔디언
     - 바이너리: 컴파일 4단계(전처리·컴파일·어셈블·링크), 최적화에 따른 코드 변화, 디스어셈블과 디컴파일 차이, 정적/동적 분석 장단점
     - GDB: 중단점·단계 실행(ni/si/finish), 레지스터·메모리 조회(i r, x, telescope), 메모리 맵(vmmap), 콜 스택(bt), 값 변조(set)
  4. **실습** — Dreamhack "Exercise: GDB" 워게임 해결
     - 함수 호출 직후 rax(반환값)를 확인해 flag1 획득
     - 조건 분기(test → jne) 때문에 실행되지 않는 함수를 set으로 레지스터 값을 바꿔 실행시켜 flag2 획득
- **산출물 링크:**

- **검증/확인 내용:**

  - 조건 분기 우회 시 레지스터를 바꾸는 시점에 따라 결과가 달라짐을 직접 실험으로 확인(비교 명령 실행 전 변경 시 성공, 실행 후 변경 시 실패)
