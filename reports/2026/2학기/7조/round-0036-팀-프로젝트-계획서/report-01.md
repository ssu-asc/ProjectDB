# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- Web 취약점 학습
- 학습 수준에 맞는 실습 환경의 필요성

## 2. 프로젝트 세부내용

- Web 취약점을 학습하고, AI가 생성한 실습 환경을 활용해 배운 내용을 응용한다.
- 풀이과정을 작성하면 AI가 개념과 풀이 방법을 정리해준다.

## 3. 프로젝트 기대효과

- 정해진 문제를 푸는 것이 아니라, 배운 취약점을 맞춤으로 실습해볼 수 있어 학습효율이 증가한다.
- 문제를 잘 해결하지 못하면 해당 부분을 AI가 기억하고 더 구체적인 학습 자료를 제공할 수 있다.
- AI를 활용해 취약점을 학습하는 법을 연습할 수 있다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- AI 아티텍쳐 설계가 어려울 수 있고, 의도치 않은 취약점을 막을 수 있어야 한다.
- 웹 페이지 전체를 LLM으로 생성하고 배포하면 API비용이 많이 들 수 있다.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- web hacking에 대한 지식이 필요하다
- 가상 환경을 구축하고 배포할 수 있는 지식 (docker)와 배포 가능한 환경이 필요하다.
- AI 아키텍쳐 설계 능력 필요하다.
