## 프로젝트 개요

> 본 프로젝트는 최근까지 활동한 Rhysida 랜섬웨어를 대상으로, 내부 동작 방식과 암호화 로직을 분석하고 이를 바탕으로 복호화 툴을 제작해보는 것을 목표로 한다. 특히 난수 생성 과정의 구현 취약점을 중점적으로 분석하고, 이를 활용한 복호화 도구를 직접 제작해보며 악성코드 분석과 개발 역량을 함께 키우고자 한다.
## 기대 효과

최신 랜섬웨어를 직접 분석해 보면서 정적 분석, 동적 분석, 암호화 로직 이해까지 폭넓게 경험할 수 있다. 또한 팀원들이 각자 역할을 나누어 협업하면서 실전형 보안 프로젝트 수행 경험과 문서화 능력을 함께 기를 수 있을 것으로 기대한다.

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)
- 최근 랜섬웨어는 단순 악성코드를 넘어 실제 기업과 기관에 큰 피해를 주는 위협으로 자리잡고 있어, 이에 대한 분석 경험이 중요하다 판단했다.
- Rhysida는 비교적 최근에 활동한 랜섬웨어로, LockBit에 비해 낮은 난이도를 가지고 있어 최신 악성코드의 구조와 동작 방식을 공부하기에 적절한 사례라고 생각했다. 
- 키 생성 과정에서 보안용 난수 생성기 대신 일반 난수 생성 로직이 사용된 구현 취약점을 분석한다.
- 단순히 분석에 그치지 않고 복호화 툴 제작까지 진행해 봄으로써, 리버싱과 개발을 함께 경험하는 실습형 프로젝트를 수행하고자 한다.

## 2. 프로젝트 세부내용

- **정적 분석**: Ghidra 및 IDA Free를 활용해 Rhysida 바이너리를 디컴파일하고, PRNG 초기화 로직과 ChaCha20 암호화 흐름을 분석한다.
- **동적 분석**: Windows 기반 격리 환경에서 샘플 실행 후 파일 생성 및 변경 과정, 랜섬노트 생성, 프로세스 행위를 모니터링한다.
- **암호화 분석**: 시드 값과 생성 키 간의 관계를 분석하고, 암호화 키 생성 방식의 취약점을 정리한다.
- **복호화 툴 구현**: 분석 결과를 바탕으로 시드 추정 및 키 복구 과정을 자동화하여, 간단한 형태의 복호화 도구를 구현한다.

## 3. 프로젝트 기대효과

- 최신 랜섬웨어에 대한 정적·동적 분석 역량을 실질적으로 향상시킬 수 있다.
- 암호학적 구현 취약점을 활용한 키 복구 과정을 직접 재현하며 보안 설계의 중요성을 체감할 수 있다.
- 분석, 구현, 검증, 문서화까지 전 과정을 수행하며 팀 프로젝트 경험과 기술 문서 작성 능력을 함께 확보할 수 있다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- **[내부] 호스트 감염 위험성**: 최신 랜섬웨어 샘플을 다루므로 가상환경 격리, 스냅샷 관리, 네트워크 차단이 필수적이다.
- **[내부] 연산 비용 문제**: 분석 결과를 실제 코드로 옮기는 과정에서 예상보다 많은 시간이 들 수 있으며, 브루트포스 범위가 넓을 경우 성능 문제가 발생할 수 있다.
- **[외부] 분석 난이도**: 최신 악성코드는 난독화 및 안티 분석 기법이 적용될 수 있어 분석 시간이 길어질 수 있다.
- **[외부] 샘플 확보 제한**: 타겟 해시랑 일치하는 Rhysida 샘플을 안전하게 구해야한다.

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- **구성원**: 4인, (정적 분석 / 동적 분석 / 암호화 분석 / 복호화 툴 개발로 역할 분담)
- **분석 환경**: Windows 10/11 기반 가상 머신, Host-only 또는 완전 격리 네트워크 환경
- **개발 언어**: Python, C/C++
- **협업 도구**: Git/GitHub, Notion
