# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 택배 배송 확인, 정부지원금, 건강검진 안내 등 사칭 문자와 메일 속 링크 클릭을 유도해 피싱 피해가 빈번히 발생하고 있다. 일반 사용자는 URL 구조에 익숙하지 않아 유명 사이트 이름을 앞에 붙인 주소에 쉽게 속을 수 있다. 본인도 피싱 문자에 속아 금전적 피해를 입은 경험이 있다. 기존 차단 목록(블랙리스트) 방식은 이미 신고된 주소만 막을 수 있고 짧게 운영되며 주소를 계속 바꾸는 피싱 사이트에는 대응이 늦는다. 그래서 차단 목록에 없는 새로운 주소도 URL 자체의 특징을 분석해 피싱 여부를 판별하는 프로그램을 개발하고자 한다.

## 2. 프로젝트 세부내용

- 입력된 URL의 형식을 정리하고, 단축 URL은 리다이렉트를 따라가 최종 주소를 확인함
- URL을 구성 요소로 분해하고, 공개 접미사 목록(PSL)을 기준으로 실제 등록 도메인을 추출함
- URL 문자열 특징(IP 주소 사용, 서브도메인 개수, 등록 도메인이 아닌 위치의 브랜드명 등)과 도메인 생성일을 판별 특징으로 사용함
- 규칙 기반 판별을 베이스라인으로 구현하고, 동일한 특징으로 머신러닝 모델을 학습시켜 성능을 비교함

## 3. 프로젝트 기대효과

- 차단 목록에 아직 오르지 않은 새로운 피싱 주소도 링크를 누르기 전에 확인할 수 있어 피해를 예방함
- URL·도메인 구조, HTTP, 피싱 수법, 머신러닝 데이터 설계 등 웹 보안 역량을 쌓음 

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- URL·HTTP 구조, 피싱 수법 등 웹 보안 지식과 머신러닝 모델 학습 경험이 부족함
- 규칙 점수와 3단계 경계값을 정하는 기준이 주관적일 수 있음

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- Python
- URL, 도메인 구조와 HTTP 지식 필요
- 머신러닝 기초
- 웹 개발 기초

## 6. 프로젝트 수행시 활용되는 장비 및 물품

## 개인 수행 계획

- **주요 수행 항목:**
    URL 피싱 관련 사전 학습 후 규칙 기반 판별기와 웹 서비스를 먼저 완성하고, 데이터를 구축해 머신러닝 모델을 학습시켜 두 방식의 성능을 비교함
- **예상 산출물:**
    피싱 URL 판별 웹 프로그램(규칙기반 + 머신러닝)
- **검증 방법:**
    실제 피해 URL과 학습 이후 정상 URL을 비교해 판별이 잘되는지 확인. 이후 새 피싱 URL 수집해 판별 성능을 확인
