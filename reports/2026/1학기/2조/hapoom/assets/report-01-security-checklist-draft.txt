# 1차 보안 점검 체크리스트 초안

## 1. 웹 서비스 구조 파악

* 주요 페이지 및 기능 목록 확인
* 로그인, 게시글, 댓글, 파일 업로드 등 입력 지점 확인
* 요청/응답 흐름 확인
* 인증 및 세션 처리 방식 확인
* 접근 권한이 필요한 페이지와 공개 페이지 구분

## 2. 네트워크 기반 점검 항목

* 도메인이 어떤 IP로 연결되는지 확인
* 웹 서비스가 사용하는 포트 확인
* HTTP/HTTPS 적용 여부 확인
* TLS 인증서 적용 여부 확인
* 외부에 불필요한 관리자 페이지 또는 서비스 포트가 노출되어 있는지 확인

## 3. 웹 취약점 점검 항목

* 입력값 검증 여부 확인
* XSS 가능성 확인
* SQL Injection 가능성 확인
* 파일 업로드 제한 여부 확인
* 인증/세션 관리 방식 확인
* 접근 제어 우회 가능성 확인

## 4. 서버 보안 점검 항목

* 서버 접근 권한 확보 여부 확인
* 서버 설정 확인 가능 여부 확인
* 파일 권한 및 계정 권한 확인 필요
* 로그 관리 여부 확인 필요
* 배포 구조 및 방화벽 설정 확인 필요

## 5. 향후 분석 방향

* 서버 내부 접근 권한이 없는 경우 블랙박스 방식으로 웹 기능과 요청/응답 흐름을 먼저 분석한다.
* 서버 내부 접근 권한이 확보되면 서버 설정, 계정 권한, 로그 관리, 배포 구조 등 내부 보안 점검으로 확장한다.
* 최종적으로 단순 취약점 목록이 아니라 위험도, 영향도, 대응 방안을 포함한 보안 체크리스트로 정리한다.
