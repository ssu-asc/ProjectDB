# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 대학 도서관 웹 시스템은 학생 개인정보(학번, 이름, 연락처)와 대출 기록 등 민감한 데이터를 다루고 있으나, 보안 점검이 체계적으로 이루어지지 않는 경우가 많다. 실제로 국내 대학 웹 서비스에서 SQL Injection, XSS, 인증 우회 등의 취약점이 보고된 사례가 지속적으로 발생하고 있다.
-

## 2. 프로젝트 세부내용

| 기능 | 포함 취약점 | 공격 시나리오 예시 |
| --- | --- | --- |
| 도서 검색 | SQL Injection | 검색창에 UNION SELECT 구문 삽입으로 DB 테이블 노출 |
| 로그인/회원가입 | 인증 우회, 세션 관리 미흡 | JWT 토큰 변조를 통한 관리자 권한 탈취 |
| 도서 상세/리뷰 | Stored XSS | 리뷰 입력란에 스크립트 삽입, 타 사용자 쿠키 탈취 |
| 좌석 예약 | CSRF, IDOR | 타인의 예약을 무단 취소하는 CSRF 공격 |
| 파일 업로드 (자료실) | 파일 업로드 취약점 | 웹셸 업로드를 통한 서버 명령 실행 |
| 관리자 페이지 | 파일 업로드 취약점 | URL 직접 접근으로 관리자 기능 노출 |

## 3. 프로젝트 기대효과

- 공격자 관점(CTF)에서의 경험을 방어자 관점의 자동화 도구로 전환함으로써, 보안 엔지니어링에 대한 종합적 이해를 갖춘다.
- 향후 숭실대 도서관 전산 담당 부서에 보안 점검 리포트를 제출하여 실제 서비스 개선에 기여하는 것을 장기 목표로 삼는다.

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 내부요인
  - 보안 지식 수준의 제약 : CTF 경험이 거의 없는 팀원들이 많으므로 스터디를 통해 실력을 보강해야 한다. 
- 외부요인
  - 법적/윤리적 제약: 실제 운영 중인 숭실대 도서관 웹사이트에 대한 비인가 스캐닝은 정보통신망법 위반에 해당하므로, 담당자의 서면 승인을 선행해야한다. 

## 5. 프로젝트 수행시 요구사항 (프로젝트 구성원, 개발환경 등)

- 웹 개발 기초에 대한 선수 지식
- Python 기본 문법
- Git/GitHub 협업 워크플로우
- 웹 보안 취약점의 개념 이해(참고 도서 및 강의를 통한 스터디로 보완)
