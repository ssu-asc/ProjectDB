## 이슈 및 해결 방안

- **문제 상황:** 외부 검증 결과 정확도가 24.9%로 지나치게 낮게 나옴. 정상 URL 대부분을 피싱으로 오판하는 문제 발생
- **해결 현황:** IsHTTPS 외에도 학습 데이터의 정상 URL이 전부 경로 없는 루트 도메인에 편향된 것이 원인으로 확인됨. 경로가 포함된 정상 URL 42만 건(malicious_phish)을 추가해 통합 재학습하고, 판정 임계값을 0.5에서 0.8로 조정해 외부 검증 정확도 72.3% 달성. Stage-1 판정 API 구축 완료
