## 이번 회차 세부 진행 내용

### 1. 버그바운티 참여 환경 구성

이번 회차에서는 실제 취약점 테스트를 수행하기 전, 파인더갭 NC 공개 버그바운티 프로그램 참여에 필요한 기본 환경을 구성하였다.

- NC 프로그램 서약 동의 완료
- 파인더갭 공식 VPN 연결 환경 구성
- 파인더갭 인증서 설치 완료
- Burp Suite 기반 요청·응답 확인을 위한 프록시 환경 준비
- 프로그램 상세정보, 공지사항, 범위 내 타깃, 제약사항 확인

### 2. 테스트 전 체크리스트

**환경**

- [ ] NC 프로그램 서약 동의 완료
- [ ] 파인더갭 공식 VPN 연결 확인
- [ ] 점검 중 VPN 연결 상태 유지 확인
- [ ] 파인더갭 인증서 설치 확인
- [ ] Burp Suite 프록시 환경 확인
- [ ] 파인더갭 제공 Burp Suite Config 적용 여부 확인
- [ ] 요청·응답이 Burp Suite에서 정상적으로 기록되는지 확인

**범위**

- [ ] 범위 내 타깃에 명시된 도메인만 점검
- [ ] 범위 내 타깃 외 모든 대상 제외
- [ ] PlayNC 커뮤니티 게시판 제외
- [ ] 퍼플 TALK/채팅 및 커뮤니티 기능 제외
- [ ] NC 해외 자회사 사이트 제외
- [ ] NC 관리범위가 아닌 Third-Party 영역 제외
- [ ] www.nc.com은 메인 페이지만 점검하고, 기업·지속가능경영·소식·IR·채용 페이지 제외

**금지사항**

- [ ] 자동화 스캔 금지
- [ ] DoS 테스트 금지
- [ ] 브루트포스, 퍼징, 무작위 대입 금지
- [ ] 실제 유저 계정 및 재화 대상 테스트 금지
- [ ] 커뮤니티 게시판 등 일반 사용자에게 노출될 수 있는 영역에 글 작성 금지
- [ ] NC 자산 또는 타 사용자 데이터를 열람·삭제·수정·공개하지 않음
- [ ] 취약점 및 테스트 진행 사항 외부 공개 금지

**테스트 방식**

- [ ] 테스트 계정 기반으로 수동 점검 진행
- [ ] 고객센터 문의 등 테스트 흔적이 남는 경우 `NC 보안 테스트 버그바운티` 또는 `NC Bugbounty TEST` 문구 사용
- [ ] XSS 테스트 시 `alert()` 대신 `console.log()` 사용
- [ ] 결제 관련 테스트 시 환불 가능 여부 및 상품 조건 사전 확인
- [ ] 취약점 가능성 확인 후 불필요한 추가 공격 중단
