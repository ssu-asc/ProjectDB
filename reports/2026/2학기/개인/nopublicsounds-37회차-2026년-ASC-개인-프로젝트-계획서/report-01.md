## 프로젝트 개요

웹 애플리케이션에서 발생하는 보안 취약점의 원인과 방어 방법을 직접 이해하기 위해 의도적으로 취약점을 포함한 웹 애플리케이션을 개발한다. 이를 대상으로 취약점별 공격 시나리오를 구성하고 실제로 취약점을 재현한 후 소스 코드와 데이터 흐름을 분석하여 취약점이 발생한 원인을 파악한다. 이후 적절한 보안 대책을 적용한 뒤 동일한 공격을 다시 수행하여 방어 효과를 검증한다.

## 기대 효과

- 주요 웹 취약점에 대한 실질적 이해
- 공격과 방어를 직접 수행하며 기술 습득
- 프론트엔드 개발 과정에서 발생할 수 있는 보안 문제에 대한 이해

# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 웹 애플리케이션은 사용자 입력, 세션 등 다양한 요소를 활용하기 때문에 다양한 보안 취약점이 존재할 수 있다. 백엔드와 함께 복잡하게 연동되는 현대적 웹 애플리케이션에서는 단순한 기능 구현을 넘어 입력 처리와 보안 정책 등에 대한 이해가 뒷받침되어야 한다. 본 프로젝트는 공격자와 개발자의 관점을 모두 경험하여 안전한 웹 애플리케이션을 설계하는 역량을 갖추는 것을 목표로 한다.

## 2. 프로젝트 세부내용

게시판, 인증, 댓글, 프로필 등의 기능을 갖춘 간단한 웹 앱을 구축한다. 프로젝트 목적에 따라 일부 기능에 의도된 보안 취약점을 포함시켜 공격 및 방어 실습이 가능하도록 구성한다. 

다음의 주요 웹 취약점들을 염두에 둔다.

- XSS
- CSRF
- Clickjacking
- SQL Injection
등등.

각 취약점에 대해 공격자가 어떤 조건에서 취약점을 발견하고 공격할 수 있는지 시나리오를 작성한다. 예를 들어 XSS의 경우 사용자 입력이 웹 페이지에 출력되는 과정을 분석하고, 악의적인 입력이 브라우저에서 실행되는 과정을 재현한다. 
또한 공격 과정에서 사용되는 요청, 입력값 및 애플리케이션의 동작을 기록하여 취약점의 재현 과정을 문서화하고 Github Repository에  남긴다.

## 3. 프로젝트 기대효과

- 주요 웹 취약점의 실제 동작 이해
- 취약점의 원인을 분석하는 능력 향상
- 공격 및 방어의 관점을 모두 함양
- 보안 지식 및 경험 확보

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 실제 웹 애플리케이션과 동일한 수준의 복잡한 환경을 구축하기 어려움

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- 현대 웹 표준
- 웹 애플리케이션의 구조 이해
- 기본적인 웹 취약점에 대한 이해

## 개인 수행 계획

- **주요 수행 항목:** 의도적으로 취약한 웹 애플리케이션 구현, 취약점 재현 및 공격 과정 분석, 취약점별 분석 및 실험 결과 보고서 작성
- **예상 산출물:** 취약하게 설계된 웹 애플리케이션, 보안 대책이 적용된 웹 애플리케이션, 공격 시나리오, 보고서, Github Repository
- **검증 방법:** 의도적으로 구현한 취약점이 실제 공격 시나리오를 통해 재현되는지 확인, 취약점별 테스트 케이스를 작성하여 반복적으로 검증
