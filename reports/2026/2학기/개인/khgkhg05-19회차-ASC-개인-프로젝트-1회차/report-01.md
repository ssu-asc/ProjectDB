# [제1차 개인 프로젝트 진행 보고서] ASC 개인 프로젝트 1회차

- **작성자:** 김홍균 (team06_02)
- **활동 기간:** 2026. 10. 26. \~ 2026. 11. 01.

## 프로젝트 진행 현황

- **이번 회차 목표:** IDA Professional 9.3 분석 환경 점검 및 분석 대상 바이너리 확정, 실행 구조와 주요 구성 파일 파악
- **현재 진행률:** 5% (초기 조사 단계)
- **주요 달성 사항:**
  - IDA Professional 9.3 실행 환경 및 프로그램 구동 상태 확인
  - `ida.exe`를 초기 분석 대상으로 선정하고, `idapro.hexlic` 등 라이선스 관련 파일의 분석 필요성 검토
  - IDA 실행 과정에서 발생하는 데이터베이스 업그레이드 안내 확인 및 `pc.dll` 파일 존재 확인
  - 라이선스 검증 메커니즘 분석을 위한 정적·동적 분석 방향 수립

## 수행 내역

- **수행 작업:**

  1. 기존에 확보한 IDA Professional 9.3을 대상으로 프로그램 실행 상태 및 구성 파일 확인
  2. `ida.exe`를 초기 분석 대상으로 선정하고, 주요 DLL 및 라이선스 관련 파일의 역할과 상호 관계를 후속 조사 대상으로 정리
  3. IDA 데이터베이스 업그레이드 과정에서 발생하는 안내 메시지를 확인하고, `proc` 디렉터리의 `pc.dll` 파일을 추가 조사 대상으로 선정
  4. 라이선스 파일인 `idapro.hexlic`의 존재 여부 및 라이선스 검증 과정이 프로그램 실행에 미치는 영향을 분석하기 위한 실험 방향 검토
  5. 프로그램 진입점 및 내부 실행 흐름을 정적 분석하고, 디버거를 이용하여 실제 실행 흐름을 검증하는 후속 분석 계획 구체화

- **산출물 링크:**

  - 현재 외부에 게시한 분석 산출물 없음

- **검증/확인 내용:**

  - 확보한 IDA Professional 9.3의 실행 가능 여부 확인
  - `ida.exe`를 초기 분석 대상으로 선정하고, 관련 DLL의 추가 분석 필요성 확인

## 이슈 및 해결 방안

- **문제 상황:**

  - IDA Professional은 여러 실행 파일과 DLL로 구성되어 있어 `ida.exe`만 분석하는 것으로는 전체 실행 구조 및 라이선스 검증 흐름을 파악하기 어려움
  - 확보한 프로그램의 구성 파일 중 어떤 모듈이 라이선스 검증에 관여하는지 아직 확인되지 않음
  - 실제 라이선스 검증이 수행되는 모듈과 함수가 특정되지 않아 본격적인 제어 흐름 분석은 진행되지 못함

- **해결 현황:**

  - 단일 실행 파일 분석에서 벗어나 주요 DLL을 포함한 모듈 단위 분석으로 범위를 확장하기로 결정
  - PE 구조, Import Table, 문자열 및 함수 간 참조 관계를 활용하여 프로그램의 초기화 과정과 관련 모듈을 우선적으로 분석할 계획
  - 디버거를 이용한 동적 분석을 병행하여 정적 분석 결과와 실제 실행 흐름을 비교 검증할 예정
  - 현재 초기 조사 단계이며, 라이선스 검증 로직 분석은 미완료

## 다음 회차 목표

1. `ida.exe`의 PE Header, Entry Point, Import Table을 조사하여 실행 파일의 기본 구조 분석
2. `ida.exe`와 주요 DLL 사이의 의존 관계 및 초기화 과정 파악
3. 문자열 및 교차 참조(XREF)를 활용하여 라이선스 검증과 관련된 함수 후보 탐색
4. 동적 분석으로 프로그램 실행 및 모듈 로딩 과정 관찰
5. 정적·동적 분석 결과를 바탕으로 주요 함수 목록과 초기 호출 관계도 작성
6. 분석 대상 파일의 버전 및 무결성 정보를 정리하여 이후 분석의 기준 확보
