# 프로젝트 세부 계획서

## 1. 프로젝트 목적 (추진배경, 취지 등)

- 정상적인 사이트에 들어갔지만 여러 광고나 피싱 사이트였던 적이 많고 최근에서 꾸준한 피싱 피해가 발생중임

## 2. 프로젝트 세부내용

- URL 특징을 바탕으로 한 위험도 판단 기능 구현
- 공개 데이터를 활용한 AI 모델 학습 및 적용
- 위험도와 판단 근거를 사용자에게 보여주는 화면 구성

## 3. 프로젝트 기대효과

- 사용자가 사전에 위험한 사이트를 인지 가능
- 전체 개발 과정을 경험할 수 있음

## 4. 프로젝트 수행시 문제점 (내외부 요인 기술)

- 정상 사이트를 위험하다고 잘못 판단할 가능성
- 공개 데이터의 품질 및 편향 문제
- 브라우저 확장 프로그램 및 개발 관련 경험 부족

## 5. 프로젝트 수행시 요구사항 (개발환경, 사전지식 등)

- 웹 개발 기초 지식
- URL 구조와 피싱 기법에 대한 지식

## 6. 프로젝트 수행시 활용되는 장비 및 물품

| 장비명/물품명 | 세부사양 |
|:---:|------|
| **H/W** | 개인 노트북 |
| **S/W** | Chrome, 개발환경 등|
| **기타(도서 등)** | 공개 데이터셋 |

- **예상 산출물: 확장 프로그램, 성능 평가 보고서**
